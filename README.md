#
**Lyric Status**

this is a pyhton script that dynamically updates your discord status to wahtever song is playing on spotify. 
Just get your dsicord token and paste it on the cmd window and then play something on spotify.
I *might* add support for apple music and such in the future.

**How to Use:**
- Download Script
- run: "pip install syncedlyrics requests
python lyrics_status.py" in cmd
-paste Discord token in cmd window
- and done!
